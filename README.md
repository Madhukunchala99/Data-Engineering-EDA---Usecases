# Data Analysis, EDA Use Cases & Power BI Dashboards

## About This Repository

This repository contains the practical data analysis work I completed as part of my AI training at Calibo AI Academy. I worked on different real-world-style use cases to understand datasets, perform Exploratory Data Analysis (EDA), identify patterns, and extract useful insights from data.

I also worked on MUCO1 sales data and created Power BI dashboards to present business insights through interactive visualizations.

## Projects and Use Cases

### 1. Banking Fraud Analysis

Worked with banking-related data to explore transaction patterns and understand how data analysis can help identify unusual activities and potential fraud indicators.

### 2. Titanic Dataset EDA

Explored the Titanic dataset to understand passenger information, examine survival patterns, analyze relationships between variables, and identify factors associated with survival.

### 3. MUCO1 Sales Analysis

Performed exploratory analysis on MUCO1 sales data to understand sales performance, examine important business metrics, identify trends, and find insights that support business decision-making.

### 4. MUCO1 Sales Dashboard using Power BI

Built Power BI dashboards using MUCO1 sales data to present the analysis in a clear and interactive format. The dashboards help users explore sales performance and understand important business metrics through visualizations and filters.

## Overall Workflow

My approach to each use case followed these steps:

1. **Understand the business problem:** Identify the purpose of the analysis and the questions that need to be answered.
2. **Understand the dataset:** Examine the columns, data types, number of records, and meaning of each variable.
3. **Data quality checks:** Check for missing values, duplicate records, inconsistent values, and other data quality issues.
4. **Data cleaning and preparation:** Handle data quality issues where required and prepare the dataset for analysis.
5. **Exploratory Data Analysis (EDA):** Use summary statistics, visualizations, and comparisons to understand distributions, relationships, trends, and patterns.
6. **Extract insights:** Interpret the results and connect the findings to the original business questions.
7. **Build Power BI dashboards:** For the MUCO1 sales use case, create visualizations and interactive filters to communicate key sales metrics and findings.
8. **Present findings:** Organize the results into a clear format so that the analysis is easier to understand and use.
